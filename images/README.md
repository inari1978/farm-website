# 写真の置き場所

写真は編集画面（Pages CMS）からアップロードする。ファイル名は自動で付け直されるので、名前を気にしなくてよい。

- 形式：JPEG・PNG・WebP（iPhone の HEIC は不可。JPEG で保存し直すか、共有時に「互換性優先」にする）
- 大きさ：スマホで撮ったままでよい。公開のときに長い辺を1600pxまで縮小し、撮影場所（GPS）などの情報を消す
- 人が写る写真は、写っている人の了解を取る
- ただし、アップロードした元の写真はGitHubの変更履歴に残り、誰でも見られる（このリポジトリは公開のため）。お客さまの家など、場所を知られたくない写真は、スマホのカメラの「位置情報を保存」をオフにしてから撮る

## 写真の向きの目安

| 使う場所 | 向き |
|---|---|
| 各ページの紹介写真（はじめまして・はじめに・どんなサービスか） | 縦長（4:5） |
| トップの「長野の畑」「作り置き」のカード | 横長（16:9） |
| 育てる予定の野菜、インスタの写真 | 正方形 |
| SNSでURLを送ったときの画像 | 横長（1200×630px） |
