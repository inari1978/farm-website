# 写真の置き場所

このフォルダに、下の名前で写真を置くとサイトに表示されます。
名前が1文字でも違うと表示されません（仮置きの模様のままになります）。

- 形式：JPEG（.jpg）
- 大きさ：横1600px程度まで。スマホで撮った写真は縮小してから置く（1枚300KB程度が目安）
- 人が写る写真は、写っている人の了解を取る

| ファイル名 | 使う場所 | 向き |
|---|---|---|
| `me.jpg` | トップ「はじめまして」 | 縦長（4:5） |
| `top-farm.jpg` | トップ「長野の畑」のカード | 横長（16:9） |
| `top-kitchen.jpg` | トップ「作り置き」のカード | 横長（16:9） |
| `farm-me.jpg` | 畑「はじめに」 | 縦長（4:5） |
| `crop-1.jpg`〜`crop-4.jpg` | 畑「育てる予定の野菜」（左から順） | 正方形 |
| `insta-1.jpg`〜`insta-6.jpg` | 「インスタで」の写真（トップは1〜3、畑は1〜6） | 正方形 |
| `kitchen.jpg` | 作り置き「どんなサービスか」 | 縦長（4:5） |
| `ai-profile.jpg` | AI相談「相談を受ける人」 | 正方形 |
| `ogp.jpg` | LINEやSNSでURLを送ったときの画像 | 横長（1200×630px） |
